# Machine Learning-Assisted Raman Spectral Fitting Pipeline
The code in this repository is the preliminary work for a machine learning-assisted pipeline designed to automate Raman spectra deconvolution. To address the challenges of each stage of the pipeline, this study proposes specific algorithms while introducing some purpose-built methods. The experiments to validate the efficacy of the selected algorithms as well as the whole pipeline were performed on synthetic and real spectra. Based on the evaluated test cases the pipeline demonstrated good initial results in curve fitting regarding both accuracy and computational efficiency. We also propose improvements and future work to handle edge cases and more complex spectra. <br>

The paper related to this code served as a final university project and it is not yet pusblished (as of September 2026). It can be read through the link below. <br>
